# FANET experiment registry

**Current status: planning only.** No training jobs or ns-3/SUMO simulations have been executed in this repository.

Each future run will be linked to its independent mission-family ID, variant, split, config, Git SHA, software environment, data/trace hashes, model/checkpoint version, and validated metric files. Run statuses must distinguish planned, completed, failed and invalid jobs.

See the [experiment protocol](../docs/experiment_protocol.md) for the 2,743-run proposal, independent calibration, comparisons, error accounting and acceptance gates. No hypothetical numbers belong in the [results registry](../results/README.md).
