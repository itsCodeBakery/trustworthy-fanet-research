# Verified results

This directory will contain **measured and validated** experiment summaries, tables, and small machine-readable outputs. Every result must identify its generating run(s), dataset split(s), metric definition, and code revision.

Do not place hypothetical numbers, hand-edited metrics, or figures that cannot be traced to recorded predictions/measurements in this directory.

Large training artifacts, checkpoints, packet traces, and raw simulator outputs are stored externally and linked through integrity-checked manifests.
